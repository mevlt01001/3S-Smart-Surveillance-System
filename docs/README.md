# AegisVision Belgeleri

Bu dizin sistemin tamamını anlatır. Hangi soruya hangi bölümün yanıt verdiği aşağıdadır.

| Bölüm | İçerik | Kimin için |
| :--- | :--- | :--- |
| [01 — Genel bakış](01-genel-bakis.md) | Sistem ne yapar, hangi parçalardan oluşur, terimler | Herkes |
| [02 — Kurulum ve çalıştırma](02-kurulum.md) | Gereksinimler, ilk kurulum, başlatma ve durdurma, portlar | Kuran kişi |
| [03 — Kullanım kılavuzu](03-kullanim-kilavuzu.md) | Arayüzün beş sayfası, adım adım işlemler | Operatör |
| [04 — Mimari](04-mimari.md) | Süreçler, iş parçacıkları, veri akışı, tasarım kararları | Geliştirici |
| [05 — Sunucu modülleri](05-backend.md) | `WebInterface/backend` altındaki her modülün görevi ve arayüzü | Geliştirici |
| [06 — API başvurusu](06-api.md) | Bütün HTTP / WebSocket / SSE uç noktaları, örnek istek ve yanıtlar | Geliştirici, bütünleştiren |
| [07 — Arayüz kodu](07-frontend.md) | `WebInterface/frontend` yapısı, kurallar, yeni sayfa ekleme | Geliştirici |
| [08 — Kurallar ve analiz](08-kurallar-ve-analiz.md) | Kural derleme, algılama planı, koşul türleri, anomali ve olay yaşam döngüsü, özetler | Geliştirici |
| [09 — Veri ve yapılandırma](09-veri-ve-yapilandirma.md) | Diskteki dosyalar, kayıt biçimleri, ayarların tamamı, ortam değişkenleri | Geliştirici, kuran kişi |
| [10 — Geliştirme ve test](10-gelistirme-ve-test.md) | Geliştirme düzeni, sistem testi, sık yapılan değişikliklerin tarifi | Geliştirici |
| [11 — Sorun giderme](11-sorun-giderme.md) | Belirtiye göre nedenler ve çözümler, bilinen sınırlar | Herkes |

Belgeler koddaki duruma göre yazılmıştır; bir davranışı değiştirdiğinizde ilgili bölümü de güncelleyin.
